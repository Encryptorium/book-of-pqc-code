Lamport one-time signatures and Merkle signature scheme for Chapter 14 of the Encryptorium Book of PQC. Implements keygen, sign, and verify for Lamport OTS at n = 256 using SHA-256, a binary Merkle tree with authentication-path extraction and verification, and the combined Merkle signature scheme that wraps 2^d one-time keys under a single published root. Standard library only; no external dependencies.
