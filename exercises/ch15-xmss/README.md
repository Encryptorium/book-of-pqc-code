WOTS+ and XMSS implementation for Chapter 15 of the Encryptorium Book of Post-Quantum Cryptography. Implements base-w encoding, the WOTS+ checksum, the hash chain, WOTS+ keygen/sign/verify at w = 16 and n = 32 (ell = 67), L-tree compression of a WOTS+ public key into a single leaf, and XMSS keygen/sign/verify over a Merkle tree with a stateful leaf counter. Standard library only; no external dependencies.

Two deliberate divergences from RFC 8391, both pedagogical. The chain function hashes `pk_seed || chain_index || step_index || value` instead of using the RFC's 32-byte ADRS structure with a pseudorandom XOR bitmask, and the Merkle nodes above the L-tree are hashed as a bare concatenation rather than with the RFC's randomized tree hashing. The domain separation those simplifications preserve is the property the construction needs: distinct inputs at every hash call. The byte-level wire format is not RFC 8391's and this package produces no interoperable signatures. Section 3.1.2 of RFC 8391 defines the chain function the production form would use, and Section 4.1.4 the randomized tree hashing.

`wots_sign_no_checksum` and `wots_verify_no_checksum` are deliberately broken variants. They exist only for the checksum-bypass forgery demonstration in `tests/ch15/test_wots_checksum_forgery.py` and must never be used to sign anything.
