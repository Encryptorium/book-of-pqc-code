WOTS+ and XMSS implementation for Chapter 15 of the Encryptorium Book of Post-Quantum Cryptography. Implements base-w encoding, the WOTS+ checksum, the hash chain, WOTS+ keygen/sign/verify at w = 16 and n = 32 (ell = 67), L-tree compression of a WOTS+ public key into a single leaf, and XMSS keygen/sign/verify over a Merkle tree with a stateful leaf counter. Standard library only; no external dependencies.

The package hashes differently from RFC 8391 in four places, all pedagogical. The chain function hashes `pk_seed || chain_index || step_index || value` instead of using the RFC's 32-byte ADRS structure with a pseudorandom XOR bitmask. The L-tree hashes `pk_seed || level || pair_index || left || right`, with no ADRS or bitmask either, and the Merkle nodes above it are hashed as a bare concatenation. The RFC hashes both with its randomized tree hashing. Messages are hashed with plain SHA-256, where the RFC's XMSS signing hashes them with H_msg, keyed by a per-signature randomizer, the root and the leaf index. The chain function's simplification keeps distinct inputs at every call, which Chapter 15's note on the chain function calls the essential property, and that note says what the formal reduction asks for beyond it. The byte-level wire format is not RFC 8391's and this package produces no interoperable signatures. Section 3.1.2 of RFC 8391 defines the chain function the production form would use, Section 4.1.4 the randomized tree hashing, Section 4.1.5 the L-tree, and Section 4.1.9 the message hashing.

`wots_sign_no_checksum` and `wots_verify_no_checksum` are deliberately broken variants. They exist only for the checksum-bypass forgery demonstration in `tests/ch15/test_wots_checksum_forgery.py` and must never be used to sign anything.
